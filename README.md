# dotfiles

Themed terminal stack — switchable across kitty, tmux, oh-my-posh and fastfetch
with one command.

| Tool | Path | Notes |
|------|------|-------|
| kitty | `.config/kitty/` | `kitty.conf` includes `current-theme.conf` + `current-font.conf` |
| tmux | `.config/tmux/` | tpm; `tmux.conf` sources `current-theme.conf`, which owns the whole status bar. Plugins are **not** vendored |
| oh-my-posh | `.config/oh-my-posh/` | `current.omp.json` wired in `zsh/.zshrc` |
| fastfetch | `.config/fastfetch/` | `config.jsonc` is generated by `set-theme` from `themes/` |
| zsh | `zsh/.zshrc`, `zsh/.zsh_plugins.txt` | antidote plugin list; `.zsh_plugins.zsh` bundle is generated, not tracked |
| git | `git/.gitconfig`, `git/.gitconfig-work` | personal by default; work identity applies under `~/Workspace/Morfius/` |

## Themes

```sh
set-theme <name>    # tab-completes
```

Switches **seven** tools at once — kitty, tmux, oh-my-posh, fastfetch, git, fzf,
bat and eza. Each theme's files are copied to a gitignored `current-*` destination
(seeded from `dive-to-the-heart` by `install.sh`), then kitty and tmux live-reload.
Run `zeload` after — the prompt and the env-var tools are per-session.

Add a theme — drop a file with the same basename in each themes dir:

| Dir | File | Note |
|---|---|---|
| `.config/kitty/themes/` | `<name>.conf` | 16 ANSI colors, cursor/border/tab, and `background_opacity`/`background_blur` |
| `.config/tmux/themes/` | `<name>.conf` | full status bar (powerline segments) + pane/message/mode styles |
| `.config/oh-my-posh/themes/` | `<name>.omp.json` | full prompt shape, not just colors — see below |
| `.config/fastfetch/themes/` | `<name>.jsonc` | `keyColor` hex + logo `color` slots 1-5 |
| `.config/git/themes/` | `<name>.gitconfig` | diff/status/branch colors — **quote hex values**, `#` starts a comment in gitconfig |
| `.config/zsh/themes/` | `<name>.zsh` | `FZF_DEFAULT_OPTS`, `BAT_THEME`, `EZA_COLORS` |

`set-theme` completes from `.config/kitty/themes/`, so a new theme shows up in tab
completion as soon as its kitty file exists.

### Prompt shapes

Each theme defines its own prompt *structure*, not just a palette:

| Theme | Shape | |
|---|---|---|
| dive-to-the-heart | minimal | `󰄖 .dotfiles   main ` |
| organization-xiii | stark, no icons | `.dotfiles — main ·` |
| twilight-town | powerline blocks | ` .dotfiles  main ` |
| castle-oblivion | powerline blocks | ` .dotfiles  main ` |
| erdtree | ornate, framed | `╭─  ~/.dotfiles ─  main` |
| frutiger-aero | rounded capsules | `󰠓 .dotfiles  main ` |

All five share the same segments: path, git (dirty/ahead/behind), root, exec time
over 2s, exit code on failure, and a clock in the right prompt. Node/Python/Go/Rust
versions use `display_mode: files`, so they appear only inside that kind of project.

## Install

Managed with [GNU stow](https://www.gnu.org/software/stow/). Repo root is `~/.dotfiles`;
the `.config` package folds into `~/.config`.

```sh
git clone <repo> ~/.dotfiles
~/.dotfiles/install.sh          # stow --restow .config  +  clone tpm
```

Or by hand:

```sh
cd ~/.dotfiles && stow -t ~/.config .config && stow -t ~ zsh
```

Then open tmux and press `<prefix> + I` (prefix is `C-s`) to install plugins.

Add to `~/.zshrc`:

```sh
eval "$(oh-my-posh init zsh --config $HOME/.config/oh-my-posh/current.omp.json)"
```

## Fonts

kitty font is swappable — `.config/kitty/current-font.conf` is gitignored (machine-local),
included by `kitty.conf`, seeded from `jetbrains-mono` by `install.sh`.

```sh
set-font <name>    # tab-completes
```

| Font | Character |
|---|---|
| `jetbrains-mono` | the default; neutral, high legibility |
| `victor-mono` | true cursive italics — good for comment-heavy code |
| `maple-mono` | rounded terminals, soft |
| `recursive-casual` | humanist and rounded; pairs with `frutiger-aero` |
| `recursive-linear` | same family, straighter — a quieter everyday face |

Live-reloads any running kitty windows (remote control is on, local socket only).
Add a font: drop a `<name>.conf` (font_family/bold_font/italic_font/bold_italic_font)
in `.config/kitty/fonts/`. Every glyph the themes use — powerline arrows, rounded
caps, branch, crown, droplet, language icons — is verified present in all of these.

## Cheatsheet

### tmux — prefix `C-s`

| Key | Action |
|---|---|
| `prefix v` | split pane vertically (side by side) |
| `prefix h` | split pane horizontally (stacked) |
| `alt+h/j/k/l` | move between panes (no prefix) |
| `prefix H/J/K/L` | resize pane (repeatable, hold) |
| `prefix z` | zoom/unzoom pane |
| `prefix g` | save session (tmux-resurrect) |
| `prefix G` | restore session (tmux-resurrect) |
| — | sessions autosave every 15 min, autorestore on tmux start (continuum) |
| `prefix s` | choose-tree session switcher |
| `prefix r` | reload tmux.conf |
| `prefix I` | install plugins (tpm) |
| `prefix C-s` | send literal Ctrl-S through to the app (vim/shell) |
| mouse | click/drag to select, resize panes, scroll |
| click a URL | open it (tmux-fzf-url — `prefix u` for fzf picker) |

### kitty

| Key | Action |
|---|---|
| `alt+←` / `alt+→` | jump word left/right |
| `cmd+delete` | delete to line start |
| `cmd+=` / `cmd+-` / `cmd+0` | zoom in / out / reset font size |

### zsh / fzf

| Key | Action |
|---|---|
| `ctrl+r` | fuzzy history search |
| `ctrl+t` | fuzzy file finder → inserts path |
| `alt+c` | fuzzy cd into subdirectory |
| `tab` | fzf-tab: fuzzy completion menu |
| `zeload` | reload `.zshrc` |
| `set-theme <tab>` | switch color theme (completes from `.config/kitty/themes/`) |
| `set-font <tab>` | switch kitty font (completes from `.config/kitty/fonts/`) |

## Notes

- Assumes Apple Silicon Homebrew (`/opt/homebrew`) — referenced in `tmux.conf` and `kitty.conf`.
- Needs a Nerd Font (JetBrainsMono Nerd Font).
- `alacritty` / `helix` / `wezterm` / `spaceship` / `lvim` configs stay on disk but are gitignored.
